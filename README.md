🌟 Users Service avec JWT 🚀

🔒 Sécurité avancée : Ce microservice gère l'authentification et l'autorisation des utilisateurs grâce à JSON Web Tokens (JWT) pour une protection optimale des données. 🛡️

👥 Gestion des utilisateurs :

📋 Inscription et connexion des utilisateurs.
🛠️ Gestion des rôles (Admin, Propriétaire, Utilisateur).
⚙️ Technologies utilisées :

☕ Java avec Spring Boot pour le backend.
🐘 PostgreSQL comme base de données robuste.
🔑 Chiffrement sécurisé des mots de passe avec BCrypt.
📂 Code source : Découvrez le projet sur GitHub et testez-le vous-même ! 👇
🔗 Lien GitHub

🎯 Objectif : Offrir un service modulaire, sécurisé et performant pour la gestion des utilisateurs dans des projets complexes.
